# **App Name**: Svensk Släktbas

## Core Features:

- Personal Details Input: Input fields for name, birthdate, birth parish, death date, death parish, and occupation.
- Life Story Input: A large text area for entering the life story of the individual, with a scrollbar if the text exceeds the visible area.
- Template Saving: Save the entered details as a template for future use with different individuals.
- Back Button: A button at the top with the text 'Tillbaka' that navigates to a user-specified URL.

## Style Guidelines:

- Primary color: Dark slate gray (#37474F) for a serious and classic tone, reflecting historical context.
- Background color: Light gray (#ECEFF1) for a clean, unobtrusive backdrop that highlights content.
- Accent color: Deep teal (#00695C) to bring a subdued, mature, understated pop to interactive elements.
- Body and headline font: 'Literata' serif, offering a literary, vintage, and slightly formal feel suitable for genealogical information.
- Two-panel layout with a smaller left sidebar for personal details and a larger right panel for the life story. A header spans both panels with the title 'Släktforskning'.
- Simple, minimal icons for UI elements (e.g., save, edit) to maintain a clean and focused user experience.
- Subtle transitions when saving or loading templates to provide smooth visual feedback.
